# 02 传感器预处理：先让输入可信

本章目标：输出可靠的 `gyro_rad_s`、加速度方向、磁场方向和采样时间。前置条件：第 1 章的禁止动力输出、校准所有权和计时边界已经明确。

参考源码：[GY86.c](../../Project/APP_FUNC/GY86.c)、[GY86.h](../../Project/APP_FUNC/GY86.h)、[IMU.c](../../Project/APP_FUNC/IMU.c#L33-L195)、[IMU.h](../../Project/APP_FUNC/IMU.h)。

## 1. 建立单位与轴向表

| 字段 | 当前单位 | 用在哪里 |
|---|---|---|
| `acc.x/y/z` | 加速度原始 LSB，已经减零偏 | 融合前归一化，或除以 8192 得到 g |
| `gyro.x/y/z` | 角速度原始 LSB，已经减零偏 | 乘换算比例 |
| `fGyro.x/y/z` | rad/s，不是 rad | 四元数微分输入 |
| `mag.x/y/z` | 磁力计原始 LSB | 校正后归一化 |
| `angle.roll/pitch/yaw` | degree | 遥测、角度外环 |
| roll/pitch 外环输出 | degree/s | 角速度内环目标 |
| `pidRoll/Pitch/Yaw` | 当前混控命令差分，约定为 us | 加减到电调基准脉宽 |
| `motor1-4` | 电调脉宽命令 us，不是实际转速 | 转换为 CCR |

当前 MPU6050 初始化设置：

- `GYRO_CONFIG=0x18`：±2000 degree/s，换算约为 `raw*2000/32768` degree/s。
- `ACCEL_CONFIG=0x08`：±4 g，8192 LSB/g。
- `SMPLRT_DIV=0`，`CONFIG=0x06`：当前配置为很低的 DLPF 带宽档，可能带来明显闭环延迟。寄存器输出频率不等于姿态控制有效带宽。

现有 `RAW_TO_ANGLE=0.0610351f`、`RAW_TO_RAD=0.0010653f` 与该量程近似对应。若改量程，两个宏和加速度校准中的 8192 都必须一起核对。

例如原始陀螺 `1638`，约为 `100 degree/s`，即 `1.745 rad/s`；把 100 直接传入四元数微分，会放大约 57.3 倍。

### 1.1 以源码实际约定为准

[九轴数据变化](../九轴数据变化.txt) 给出的关系：

| 操作 | 姿态变化 | 对应陀螺变化 |
|---|---|---|
| 前倾 | pitch 增加 | gyro.x 为负 |
| 右倾 | roll 增加 | gyro.y 为正 |
| 逆时针偏航 | yaw 增加 | gyro.z 为正 |

这与常见“roll 绕 X，pitch 绕 Y”的命名不同。`Motor_Calc()` 用 `fGyro.y` 控 roll，用 `-fGyro.x` 控 pitch。不要一边保留源码欧拉角公式，一边把 gyro.x 直接当 roll 反馈。

为了避免混淆，数学推导中的 B 系取为四元数输入所使用的算法轴，不提前断言它就是 FRD/NED。记录板上三轴、安装朝向和实际转动；若以后统一为标准机体系，必须同时修改输入映射、四元数初始化、欧拉角输出、PID 反馈和混控。

## 2. 先保证读取错误能被看见

现有 `i2cread()` 忽略 START/ACK 返回值，并始终返回 0；上层 `if (!i2cread(...))` 就总认为成功。

建议保留现有“0 成功，非 0 错误”的接口语义，按以下顺序补齐：

1. START 失败立即退出，必要时尝试结束总线事务。
2. 检查设备地址、寄存器地址、重复 START 和读地址各阶段 ACK。
3. 只在完整接收成功后返回 0，失败返回阶段错误码。
4. 上层检查锁获取结果；读失败也释放锁，递增错误计数，不解析未完成缓冲区。
5. IMU 必需样本失败时不发布新的有效姿态；磁力计单独失败时可进入六轴模式，不能伪造磁场为新数据。

接口级控制流，不是可独立编译的补丁：

```c
/* type, buffer and error policy must be defined in the actual driver. */
OSMutexPend(IICMutex, timeout_ticks, &err);
if (err != OS_ERR_NONE) {
    return READ_LOCK_ERROR;
}
status = i2cread(address, reg, length, buffer);
OSMutexPost(IICMutex);
if (status != 0) {
    return READ_BUS_ERROR;
}
/* Decode only a complete successful read. */
```

不要在姿态任务里遇到错误就循环重试到成功，会让 PID 和安全处理长期得不到运行机会。限制本轮工作量，错误由计数、失效快照和安全策略处理。

## 3. 有符号原始数据解析

MPU6050 14 字节顺序为：加速度 XYZ、温度、陀螺 XYZ。HMC5883L 六字节顺序是 X、Z、Y，因此源码 `mag.y` 取 `[4],[5]`，`mag.z` 取 `[2],[3]`。

先拼为无符号 16 位，再按二进制补码得到有符号数。下面辅助函数避免“先转窄有符号数再比较 0x7fff”的混乱：

```c
static int16_t Decode_S16_BE(uint8_t high, uint8_t low)
{
    uint16_t bits;
    int32_t value;
    bits = ((uint16_t)high << 8) | (uint16_t)low;
    value = bits;
    if (value >= 32768) {
        value -= 65536;
    }
    return (int16_t)value;
}
```

手算测试：

| 字节 | 应得到 |
|---|---:|
| `00 00` | 0 |
| `7F FF` | 32767 |
| `80 00` | -32768 |
| `FF FF` | -1 |

源码的 `mag.x` 和 `initMx` 已是 `int16_t`，比较 `>0x7fff` 通常永远不成立；赋值过程在目标平台上可能已完成补码解释，但这些判断既不能提供额外保护，也容易误导。正确偏移量是 65536，不是 65535；不要照抄后续减 `0xffff` 的逻辑。

减零偏建议先用 `int32_t` 中间量，检查范围后再保存，避免原始极限值减偏置后又溢出到相反符号。

## 4. 重写校准的小步骤

### 4.1 陀螺零偏

静止时理想角速度是 0。对 N 个有效新样本：

\[
b_x=\frac1N\sum_{k=1}^{N}g_{x,k},\qquad
\omega_x=(g_x-b_x)\cdot RAW\_TO\_RAD
\]

其余两轴相同。当前源码使用约 100 个样本，数量不是品质保证：摇晃中的 100 个样本会把真实转动估成偏置。

动手步骤：

1. 姿态任务独占校准状态；用单独的原始局部样本累计，不混入已减偏数据。
2. 建立“等待静止 → 累计 → 检验 → 完成/重试”状态。
3. 静止条件根据本机日志确定：陀螺模长小、加速度模长接近 1 g、窗口方差小。这里不提供通用可靠阈值。
4. 检测到运动时重置累计，输出进度和原因；不会默默标成完成。
5. 完成后只提交一次偏置，再开始正式解算。记录偏置和板温，重启可比较重复性。

### 4.2 水平加速度零偏

加速度计测量比力，不是直接测重力。静止时模长约为 g；自由落体模长接近 0。融合使用的是静态方向约束，运动加速度会破坏它。

现有算法水平静置目标是 `(0,0,8192)`：

\[
b_{ax}=\bar a_x,\quad b_{ay}=\bar a_y,\quad
b_{az}=\bar a_z-8192
\]

因为必须保留 1 g，不能把三个均值全部减成零。若实测水平 z 为 -8192，先核对安装轴向与参考方向，不要硬减 +8192。

此方法只适用于已确认的水平姿态。不能把“启动时向右倾斜”当作 x/y 零偏扣掉，否则会把错误姿态写进校准参数。本指南不要求六参数高斯牛顿标定。

验收时可把板子分别放在六个面上，只检查量程、符号、模长和残余偏差；这是多姿态验证，不等于已经实现六面比例标定。

### 4.3 气压校准从主线移出

当前 `pressOffset` 清零依赖同一个校准函数，且 MS5611 初始化被注释。只做姿态控制时：

- 不创建高度任务或明确禁止它参与核心控制。
- 姿态准备条件只包含已验证的 IMU 校准、姿态初始化和新鲜数据。
- 不用“把所有标志强制清零”绕过检查。

以后恢复高度时再独立验证 PROM、温压补偿、时间和单位。本次不实现定高环。

## 5. 磁力计的必要处理

源码注释“磁力计无需零偏校准”不能作为航向可靠性的依据。磁力计与陀螺不同，但仍会受到硬铁偏置、软铁形变、电机与电源线干扰。

本主线的最低要求：

1. 验证器件身份、连续模式、X/Z/Y 顺序、三个轴与 MPU6050 算法轴的对应。
2. 使用新数据/就绪状态或独立采样时间记录磁样本。初始化注释标称约 75 Hz，不要把每次 1 tick 读取都当作新磁场。
3. 看静止模长、各方向转动和装机后的变化；必要时使用文档第 2 页的简单 min/max 偏置校正：

\[
b_{mx}=(m_{x,\max}+m_{x,\min})/2,\quad m'_x=m_x-b_{mx}
\]

这只消除部分硬铁偏移，不是完整软铁校准。若不能得到可靠航向，先保留六轴融合和 yaw 角速度控制，不声称已经完成稳定航向锁定。

## 6. 归一化不是万能预处理

对方向向量：

\[
\hat a=a/\sqrt{a_x^2+a_y^2+a_z^2}
\]

三轴共同乘一个正比例不会改变方向，因此 raw 也可用于方向归一化。但轴间比例差异、偏置、轴映射错误无法靠归一化消除。

归一化前先检查模长和数值有效性，并保留未归一化模长用于异常门控。不能把已归一化模长等于 1 当作“静止且数据可靠”的证据。

源码 `invSqrt()` 使用指针重解释，存在严格别名/平台依赖；对零输入也不是可靠的有效性检查。学习阶段先用 `1.0f/sqrtf(n2)` 和明确的正数/有限数检查，等正确性通过后再优化。Keil 项目 C99 未启用，使用 `isfinite` 前要核对实际工具链和项目 `math.h` 支持，必要时封装工具链适配函数。

## 7. 日志怎么采才不丢信息

当前 `Send_Senser()` 入参全部为 `int16_t`，但 `Task_COM` 先把 gyro 乘 `RAW_TO_ANGLE` 再传入，所以小于 1 degree/s 的变化会被截掉；不能用它来精确评估静止陀螺噪声。

`Send_5_float()` 也把每个 float 转成 `int16_t`，并不是 IEEE754 浮点发送。`Send_Attitude()` 才是角度乘 100 的定点发送。

建议为校准/回放增加独立记录格式，先定协议再改上下位机：

| 字段 | 建议语义 |
|---|---|
| 时间/序号 | 原始采样时间 us、样本序号 |
| 三轴 gyro | 原始 LSB，主机再换算 |
| 三轴 acc/mag | 原始值及各自有效标志 |
| 状态 | 校准进度、错误计数、是否新磁样本 |

只由 COM 发送；高频任务存数据或统计，不在每次采样里串口打印。既有匿名协议帧不要静默改变单位，否则上位机看似正常但物理量错误。

## 8. 动手与验收

1. 保持动力断开，先完成读取结果和解析测试。
2. 采 60 秒静止原始数据，统计均值、标准差、加速度模长与实际采样间隔。
3. 单独旋转三个轴，记录轴映射和正负；停止转动后陀螺回到零附近。
4. 水平校准后换六面检查；确认未扣掉重力。
5. 故障注入优先使用软件模拟错误码；验证无新有效快照、错误计数增加且锁仍能再次取得。
6. 关闭高度任务后，IMU 校准仍能独立完成。
