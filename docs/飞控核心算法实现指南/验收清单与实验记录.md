# 验收清单与实验记录

本文件是用户后续实施时填写的模板。**所有方框初始未勾选，表示未在本轮完成硬件或固件验收。** 本轮交付的是指南，不是已修改并飞行验证的控制器。

## 1. 一次只推进一个阶段

| 关卡 | 最小任务 | 必须保留的证据 | 通过后允许做什么 |
|---|---|---|---|
| 0 | 禁止动力输出；核对任务、校准和计时 | 安全状态、任务周期日志 | 原始采样 |
| 1 | 读取错误传播、解析、零偏与轴向 | 原始CSV、偏置、六面方向表 | 四元数预测 |
| 2 | 初始化、积分、归一化、角度输出 | 合成样本测试、单轴记录 | 加速度融合 |
| 3 | 比例反馈、必要积分、观测门控 | 静止与偏差收敛曲线 | 九轴验证、PID影子 |
| 4 | 快照、速率P/PI/PD/PID、角度外环 | 目标/反馈、P/I/D和饱和日志 | 混控影子 |
| 5 | 电机映射、安全出口、PWM测量 | 通道表、脉宽、故障测试 | 无桨电机验证 |
| 6 | 无桨方向与停机、失联检查 | 转向表、故障动作、实际限制 | 合规推力台架评估 |

不是按日期推进：今天没有通过关卡 1，就不因为时间到了而启用 PID 输出。

## 2. 工程与任务

- [ ] 编译基线和实际 Keil 版本记录。
- [ ] 检查源码/参考算法/注释掉功能的边界。
- [ ] 明确 `Quat_Init` 在当前启动流程中的位置。
- [ ] 学习阶段电机动力断开且输出受禁止条件控制。
- [ ] 高度任务不阻塞 IMU准备条件。
- [ ] 校准累加器有唯一写入任务。
- [ ] 锁创建/获取错误被检查，读失败仍释放锁。
- [ ] 姿态、PID、COM的实际间隔与耗时分别记录。
- [ ] 临界区只复制快照，不含I²C/串口/数学运算/OS阻塞。
- [ ] PID与遥测读取完整快照，有时间戳、序号和有效标志。

## 4. 四元数与融合

- [ ] 单位四元数输出三角为零。
- [ ] x轴+30度按源码输出pitch=-30度。
- [ ] y轴+30度按源码输出roll=+30度。
- [ ] z轴+90度输出yaw=+90度。
- [ ] `q`与`-q`表示同一姿态。
- [ ] 保存旧四个分量后统一积分。
- [ ] 四元数归一化与非有限数检查通过。
- [ ] `asin`限域，不以限域掩盖坏四元数。
- [ ] 单轴方向误差能校正，不要求三个分量同时非零。
- [ ] AHRS反馈积分用完整dt，与四元数半周期区分。
- [ ] 动态acc或mag异常不重置为假水平。
- [ ] 六轴yaw漂移与九轴航向能力分别记录。
- [ ] 九轴初始化与更新分支参考轴/符号一致。

## 5. PID与混控

- [ ] 内环目标与反馈单位一致，先独立速率环再接角度外环。
- [ ] Ki、Kd关闭时不产生除零。
- [ ] 积分累计真实历史时间。
- [ ] 首次测量D为零，设定值阶跃不制造D冲击。
- [ ] D滤波与传感器滤波延迟一起评估。
- [ ] 输出/积分贡献/外环目标分别限幅。
- [ ] 停机、失联、无效姿态时复位状态。
- [ ] 电机饱和信息被记录并用于积分管理。
- [ ] roll摇杆实际幅度为±15度，与注释区别记录。
- [ ] yaw保持角速度控制语义，不混为航向角。
- [ ] 验证yaw混控号与电机真实转向。
- [ ] 逐台确认motor逻辑号与TIM3通道。
- [ ] 所有演示基准油门仅用于影子测试，不直接输出。

## 6. 故障注入表

优先软件注入或无动力条件下模拟，不带桨拔线或手持测试。

| 故障 | 注入方式 | 应发生 | 实测 |
|---|---|---|---|
| IMU读失败 | 模拟一次/连续错误返回 | 无伪造新快照，安全处理，锁可再次获取 | 待填 |
| 磁力计失效 | `mag_valid=0` | 六轴降级，不重置四元数 | 待填 |
| 姿态过期 | 停止发布时间推进 | PID识别过期，安全输出和复位 | 待填 |
| 时间异常 | 首帧/大间隔/极小间隔 | 不产生巨大积分或微分 | 待填 |
| 计算NaN | 软件设置异常输入 | 不进行非法CCR转换 | 待填 |
| RC脉冲停止 | 无动力下停止输入 | 各路过期检查触发 | 待填 |
| 发射机关闭 | 无动力测试接收机 | 核对接收机failsafe，不沿用高油门 | 待填 |
| 超角度 | 软件输入或无动力倾斜 | 故障锁存/安全命令，PID复位 | 待填 |
| 输出饱和 | 影子模式持续误差 | 无界积分被阻止，退出可恢复 | 待填 |

## 8. 怎样宣布完成

结论应按证据写，例如：

“已完成四元数与六轴反馈的软件测试，完成无动力板上轴向和静止验证；速率和角度PID已通过软件状态测试，PWM与无桨映射检查通过。带推力的闭环调参和实际飞行尚未验证。”

不要把“Keil编译通过”“无桨能转”“上位机姿态看起来正常”中的任何一个单独写成“飞控稳定、可直接飞行”。
