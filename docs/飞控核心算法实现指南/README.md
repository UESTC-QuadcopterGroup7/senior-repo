# 从驱动与 µC/OS-II 到姿态闭环：代码实现指南

编写基线：2026-10-22，仓库 `Project/exp4.uvprojx`，目标 STM32F401RE。

## 1. 这份指南解决什么

你的学习起点是：已经完成基本驱动和 µC/OS-II 移植，现在准备自己理解、实现并验证姿态解算和 PID。

仓库里虽然已有 `IMU.c`、`pid.c` 的参考实现，但“源码已有”不代表“你已经完成”。本指南把它们当作工程参照，带你按小步骤实现，而不是让你直接复制一套算法后上电试飞。

**本次只新增文档，没有改动固件。文中 C 代码是学习或接口示例，除非明确列出了全部依赖，不是可直接烧录的完整补丁。**

完成目标：

```mermaid
flowchart LR
    A["可靠传感器样本<br/>轴向、单位、校准、时间戳"] --> B["四元数预测"]
    B --> C["Mahony 风格反馈融合"]
    C --> D["姿态角与角速度快照"]
    D --> E["角度外环 P"]
    E --> F["角速度内环 PID"]
    F --> G["四电机混控"]
    G --> H["安全判断与 PWM 输出"]
    D --> I["低优先级遥测"]
    H --> I
```

不要求完成代码没有采用的 Madgwick、EKF、高斯牛顿优化、完整动力学仿真或 DARTS。磁力计只围绕已有九轴融合解释必要的可靠性处理，不引入椭球优化算法。高度部分只交代现状与启动依赖，不要求实现定高飞行。

## 5. 开发纪律与安全边界

1. 所有初期硬件测试先拆除四个螺旋桨。姿态算法测试优先断开电机动力电源，仅给控制板和传感器供电。
2. `1000 us` 是代码约定的最低电调命令，不是经过实测的“绝对停转保证”。必须单独确认电调行为。
3. 在禁用自动电机输出的学习目标中推进；只把 `PWM_EN` 设为 0 并不完整，因为主任务仍直接访问 TIM3 和调用输出函数。
4. 使用 Keil 打开 `Project/exp4.uvprojx` 构建。仓库没有可直接使用的 Makefile，不把 `make` 写成已验证的编译方法。
5. 增加源文件时，在 Keil 分组中加入并核对头文件路径；文中建议结构也可先放进现有 `.c/.h`，不用先重构整个工程。
6. 核对 [引脚配置](../引脚配置.txt)、[电压分配](../电压分配.txt)，不要把软件示例当作接线依据。
7. 无桨电机测试只能验证信号、转向、混控趋势和部分噪声，不能证明有桨闭环稳定性。

## 6. 最先做哪三件事

1. 读第 1 章，建立“仅采样与遥测、始终禁止动力输出”的开发状态，并解耦气压校准。
2. 读第 2 章，记录 60 秒静止输入，核对三轴符号、量程、数据解析和实际 `dt`。
3. 读第 3 章，在无动力条件下只实现四元数积分，验证已知单轴转动。

这些通过以后，再加融合、PID。教程中的演示数值用于手算和软件测试，不是推荐飞行参数；实际滤波、增益、超时和保护阈值由本机数据决定。
