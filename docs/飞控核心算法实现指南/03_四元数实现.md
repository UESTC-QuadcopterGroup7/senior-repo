## 2. 先确定数学约定

采用标量在前的 Hamilton 四元数：

\[
q=(q_0,q_1,q_2,q_3)=(w,x,y,z)
\]

本章定义 `q=q_NB`，将算法机体系 B 的向量旋转到参考系 N：

\[
(0,v_N)=q\otimes(0,v_B)\otimes q^*,\qquad
q^*=(w,-x,-y,-z)
\]

这里的算法轴与源码输入匹配，不直接宣称 N 为标准 NED。源码在单位四元数时把加速度参考定为 +z，磁水平参考定为 +y，和部分讲义的参考方向不同。

两个四元数 `a=(a0,av)`、`b=(b0,bv)` 的 Hamilton 乘法是：

\[
a\otimes b=(a_0b_0-a_v\cdot b_v,\ 
a_0b_v+b_0a_v+a_v\times b_v)
\]

先后顺序不能交换。若更改四元数表示方向，微分、参考向量和欧拉角公式也要配套改变。

旋转轴为单位向量 `u`、角度为 `theta`：

\[
q=\left(\cos\frac{\theta}{2},u_x\sin\frac{\theta}{2},
u_y\sin\frac{\theta}{2},u_z\sin\frac{\theta}{2}\right)
\]

半角不是采样周期的一半，两者不要混淆。`q` 与 `-q` 描述相同旋转；四个分量有单位长度约束，所以只有三个姿态自由度。

## 3. 第一步：安全初始化

纯陀螺学习阶段，已确认机体水平时先取 `(1,0,0,0)`，表示把当前水平朝向作为临时参考，而不是已经找到了真北。

现有 `Quat_Init()`：

1. 读取磁力计。
2. 设 `initRoll=initPitch=0`。
3. 用磁场计算 `initYaw`，水平时化简成 `atan2(initMx,initMy)`。
4. 转成四元数。

它在校准前执行，读取失败后局部磁变量还可能未赋值。不要把它原样当作通用初始化。

建议实施：

- 校准与有效样本就绪前，不允许 PID 输出。
- 六轴学习阶段水平静置后显式重置 `q` 与反馈积分。
- 九轴阶段先验证磁场和轴向，再设置初始 yaw；无有效磁场则保留相对航向并标记模式。
- 任意倾斜开机不在当前水平初始化能力内，先不要声称支持；需要时另行推导初始倾角或等待可靠收敛后允许控制。
- 重置时间历史；首帧仅建立基准，下一帧才正常积分。

水平且磁 yaw 为 `psi` 时，四元数应简化为：

\[
q=(\cos(\psi/2),0,0,\sin(\psi/2))
\]

用 0、90、-90 度检查，注意传给 `sinf/cosf` 的是弧度。

## 4. 第二步：只实现陀螺积分

陀螺仪给出机体系角速度 `omega=(gx,gy,gz)`，单位 rad/s。对上述 `q_NB` 定义：

\[
\dot q=\frac12q\otimes(0,g_x,g_y,g_z)
\]

展开：

\[
\begin{aligned}
\dot q_0&=(-q_1g_x-q_2g_y-q_3g_z)/2\\
\dot q_1&=( q_0g_x+q_2g_z-q_3g_y)/2\\
\dot q_2&=( q_0g_y-q_1g_z+q_3g_x)/2\\
\dot q_3&=( q_0g_z+q_1g_y-q_2g_x)/2
\end{aligned}
\]

这与《陀螺仪姿态更新》第 4 页机体系微分、以及源码四条更新式一致。离散化采用前向欧拉：

\[
q_{k+1}=q_k+\dot q_k\,dt
\]

教学函数，使用现有全局 `q0-q3`，调用前必须校验输入与 `dt`：

```c
static void Quat_Integrate(float gx, float gy, float gz, float dt)
{
    float w, x, y, z, half_dt;
    w = q0;
    x = q1;
    y = q2;
    z = q3;
    half_dt = 0.5f * dt;

    q0 = w + (-x * gx - y * gy - z * gz) * half_dt;
    q1 = x + ( w * gx + y * gz - z * gy) * half_dt;
    q2 = y + ( w * gy - x * gz + z * gx) * half_dt;
    q3 = z + ( w * gz + x * gy - y * gx) * half_dt;
}
```

为什么必须保存旧值：四条方程是同一时刻的状态。如果第一行改了 `q0`，后面的行再用新 `q0`，就变成不同的离散算法。

源码 `Get_AHRS_Time()` 返回 `dt/2`；若使用它，不要再把 `halfT` 乘 0.5。建议把接口改成返回完整 `dt`，仅在积分函数内取半周期，更容易避免积分反馈也误用半周期。

## 5. 第三步：每轮归一化

\[
n=\sqrt{q_0^2+q_1^2+q_2^2+q_3^2},\quad q_i\leftarrow q_i/n
\]

前向欧拉积分会使长度偏离 1。单位四元数旋转矩阵和后续反三角函数都依赖这个约束。

实现顺序：

1. 检查四个分量均为有限数。
2. 检查 `n2` 大于防止除零的正阈值。
3. 用 `sqrtf` 计算后归一化。
4. 无法归一化则发布无效姿态并进入故障状态；不要悄悄重置为水平然后立即允许电机输出。

记录 `n2-1` 或 `n-1`，不仅记录欧拉角。若使用快速逆平方根，误差容限须根据它的近似精度放宽；优先用精确版本建立基线。

## 6. 第四步：输出项目约定的欧拉角

保留源码现有公式：

\[
\begin{aligned}
roll&=\arcsin(2(q_0q_2-q_1q_3))\\
pitch&=-\operatorname{atan2}(2(q_0q_1+q_2q_3),q_0^2-q_1^2-q_2^2+q_3^2)\\
yaw&=\operatorname{atan2}(2(q_0q_3+q_1q_2),q_0^2+q_1^2-q_2^2-q_3^2)
\end{aligned}
\]

弧度结果乘 `RAD_TO_ANGLE` 输出 degree。`asin` 输入先限制到 [-1,1]，但这个限幅不能代替有限数与归一化检查。

小角度近似：

\[
roll\approx2q_2,\quad pitch\approx-2q_1,\quad yaw\approx2q_3
\]

所以本项目的 roll 主要关联算法 y 轴，pitch 关联算法 x 轴的负方向。

`atan2` 的 yaw 通常在 [-180,180] 度，跨边界时显示会跳变，不能直接把 +179 和 -179 相减当作 358 度误差。当前 yaw 只计划角速度内环，不需要引入航向角外环。

四元数避免积分表示的万向锁，但欧拉角输出仍有奇异姿态；源码 `roll=asin(...)` 的范围是 [-90,90] 度。闭环在小角度区工作，本教程不宣称现有欧拉角控制支持任意翻滚。

## 7. 必须做的手算与软件测试

### 7.1 单步正向 z 旋转

初值 `q=(1,0,0,0)`，`gz=pi/2 rad/s`、`gx=gy=0`、`dt=0.01 s`：

\[
q_{raw}=(1,0,0,0.00785398)
\]

归一化后 `q0≈0.999969`、`q3≈0.00785374`，yaw 约为 +0.900 度。

重复 100 步后应接近 +90 度；前向欧拉有小误差，不要求位级相等。

### 7.2 单轴已知四元数

| 输入姿态 | 四元数 | 按源码应输出 |
|---|---|---|
| 零姿态 | `(1,0,0,0)` | 三角均为 0 |
| 算法 x 轴 +30 度 | `(cos15°,sin15°,0,0)` | pitch=-30，roll≈0 |
| 算法 y 轴 +30 度 | `(cos15°,0,sin15°,0)` | roll=+30，pitch≈0 |
| 算法 z 轴 +90 度 | `(cos45°,0,0,sin45°)` | yaw=+90 |
| 同一旋转取负号 | 上述四分量均取负 | 输出同一旋转 |

表中度数只是表示角度，代码里的三角函数必须先转换为弧度。

### 7.3 异常测试

- `gx=gy=gz=0`：多轮后姿态不变。
- 以不同正常 `dt` 切分同样 1 秒恒定角速度：结果接近，同样总时间必须用各步时间之和。
- 零长度四元数、NaN、无效 `dt`：结果不能发布为有效。
- 时间基准初始化后等待很久：下一帧必须走异常/重新建立基准，不造成巨大转角。

## 8. 上板动手顺序

1. 将融合反馈暂时设为不参与，保持只有积分；仍不启用电机输出。
2. 校准完成后水平初始化，记录四元数范数、角速度和角度。
3. 用可重复的固定角度转动依次验证 ±30、±60 度，转完静置。
4. 验证角度方向符合第 2 章的实际安装约定。
5. 静置记录漂移。只要零偏剩余 0.1 degree/s，60 秒就可能积累约 6 度；这是下一章要修正的原因，不立即归因于积分公式错误。
