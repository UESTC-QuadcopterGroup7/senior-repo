本目录是对仓库根目录 `task.txt` 的逐题技术解答。每个挑战都有独立文件，内容按照“数学模型 → 代码路径 → 数值/硬件含义 → 风险 → 可复现实验”组织，不把尚未实现的功能误写成现有功能。

本轮补充把原来的 overview 展开为逐公式、逐数据流的说明：每章都包含至少一个手算例、C/Python 代码片段、单位/坐标约定、异常路径和验收指标。代码片段用于解释和离线验证，除非明确标注，不应直接烧录到飞控。

## 阅读代码的主路径

上电后 `BSP_Init`（`Project/BSP_SELF/BSP.c`）配置 SysTick、USART6、软件 I²C、MPU6050/HMC5883L、TIM3/TIM5 PWM 和两个计时器。`main.c` 初始化 µC/OS-II，然后创建四条功能任务：

```text
Task_Angel  : 读取加速度/陀螺/磁场 → 姿态四元数与欧拉角（约 1 tick）
Task_Height : 读取 MS5611 → 气压高度（当前初始化调用被注释）
Task_PID    : 遥控 PWM → 期望值 → PID → 电机混控与输出（约 3 tick）
Task_COM    : 组装串口帧发送传感器、姿态、PID 和电机数据（约 10 tick）
```

全局状态集中定义在 `main.c`，其他模块用 `extern` 访问。分析或修改时必须同时核对四件事：坐标轴正方向、物理单位、任务实际周期、共享变量同步。特别注意当前实现的边界：`i2cread` 始终返回 0，HMC5883L 的符号转换代码有缺陷，偏航 PID 调用被注释，MS5611 初始化也被注释；详见对应分题。

## 代码事实与影响速查

| 代码事实 | 直接影响 | 对应章节 |
| --- | --- | --- |
| `Attitude_Update` 用四元数积分，`Kp/Ki` 做叉乘 PI 修正 | 当前是 Mahony 风格，不是严格 Madgwick | 1、2、8 |
| `MPU6050_Offset` 固定 100 点、Z 轴减 8192 | 只适用于水平、±4 g 的初始标定 | 4、6 |
| HMC5883L 约 75 Hz，姿态任务约 1 ms | 不能把每次读取都当成新磁场样本 | 5、8 |

| 串口 `Send_5_float` 将 `float` 转成 `int16_t` | 离线分析会丢失小数和真实浮点格式 | 6 |

## 统一符号、单位和阅读规则

文档统一使用 `B` 表示机体系、`N` 表示导航系；`R_NB` 表示 B→N 的方向余弦矩阵，四元数按 `(q0,q1,q2,q3)=(w,x,y,z)` 排列。源码中的 `fGyro` 是 rad/s，`angle` 和遥控期望值是 degree（偏航期望值注释意图为 deg/s），加速度/磁场在进入 AHRS 前仍是 raw LSB。凡是涉及符号的结论，都以 [`docs/九轴数据变化.txt`](../docs/九轴数据变化.txt) 和无桨实测为准；变量注释不能替代坐标系定义。

阅读每章时建议按以下顺序核对：

1. 先看“代码定位”和数据单位，确认引用的是当前源码而不是注释掉的旧实现；
2. 再手算章节中的最小例子，检查轴序、符号、量纲和时间步；
3. 最后执行离线回放/无桨实验，并记录原始数据、固件版本、定时器周期和安全状态。

## 已知实现与建议实现的边界

章节中用“当前代码”描述已在 `Project/` 中执行的路径，用“建议/骨架/伪代码”描述待验证的改进。当前仓库没有 Makefile、主机测试框架或可依赖的 Git 提交历史；验证命令应以 Keil 工程 `Project/exp4.uvprojx` 和自建的主机回放脚本为准。文档指出的缺陷（I²C 返回值、磁力计补码、偏航 PID、MS5611 初始化、定时器时间尺度等）均来自静态源码检查，修复前应先在台架上复现并保留日志。

## 建议的验证顺序

先离线回放串口原始数据验证单位和公式，再在无桨状态检查轴向、PWM 最小值和 ±65° 倾覆保护，最后才进行低油门悬停。每次实验记录固件版本、传感器量程、采样周期、控制参数和原始数据；不要仅凭“能飞”判断算法正确。

## 挑战之间的依赖关系

```text
1 刚体/坐标  →  2 四元数表示  →  4/5 传感器标定与预处理
                     ↓                    ↓
                 8 AHRS 姿态  ←────  6 优化/数据回放
                     ↓
                 7 PID 闭环  →  3 四轴混控、PWM 与安全输出
```

沿这条链路排查时，应先验证上游的单位和坐标，再判断下游的增益；否则传感器轴向错误会被误诊为 PID 参数问题。
