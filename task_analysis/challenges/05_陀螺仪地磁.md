# 挑战 5：陀螺仪和地磁数据采集及处理

**代码定位：** [`Project/APP_FUNC/GY86.c`](../../Project/APP_FUNC/GY86.c#L23) 的初始化；[`Project/APP_FUNC/IMU.c`](../../Project/APP_FUNC/IMU.c#L146) 的读取、单位转换和磁场重排；软件 I²C 在 [`Project/APP_FUNC/iic.c`](../../Project/APP_FUNC/iic.c#L233)。

## 1. 陀螺仪的物理量和单位

陀螺仪测量机体角速度 `ωᴮ=[p,q,r]`，不是姿态角。姿态由积分得到：

\[
\Delta\theta\approx\boldsymbol\omega_k\Delta t,
\qquad \theta_{k+1}=\theta_k+\Delta\theta,
\]

但直接积分会累积零偏误差：若偏置为 `0.5°/s`，10 s 后就会产生约 5° 的姿态漂移。因此陀螺仪提供高频短期信息，加速度/磁场提供低频绝对参考。

区分噪声类型可以使用 Allan 方差。对采样序列 `ω[k]`，先按平均时间 `τ` 分组，计算相邻组均值差的平方平均；随 `τ` 变化的斜率可区分白噪声（约 `τ⁻¹/²`）、偏置不稳定和随机游走。这样可以选择零偏校准窗口，而不是任意固定 100 点。若采样频率约 1 kHz，100 点只覆盖约 0.1 s；这对低频温漂几乎没有观测能力。

`GY86.h` 配置 `MPU6050_GYRO_CONFIG=0x18`，量程为 ±2000°/s，灵敏度为 16.4 LSB/(°/s)。代码中的两个换算常量：

```c
#define RAW_TO_ANGLE 0.0610351f // 1/16.4，deg/s
#define RAW_TO_RAD   0.0010653f // RAW_TO_ANGLE * PI/180
```

`GY86_Read` 减去 `offsetGyro` 后将数据乘 `RAW_TO_RAD` 写入 `fGyro`；`Task_Angel` 把 `fGyro` 传给姿态解算，`pid.c` 又把它乘 `RAD_TO_ANGLE` 作为角速度环反馈。单位链路应保持为 raw → rad/s → deg/s，不能重复或遗漏一次转换。

## 2. MPU6050 读取流程

`MPU6050_Init` 首先读取 `WHO_AM_I (0x75)`，然后设置唤醒、采样分频、数字低通、陀螺量程和加速度量程。`SMPLRT_DIV=0` 的理论采样率取决于内部陀螺采样率和 DLPF 设置，不能只看注释中的“1000 Hz”；应查芯片时序并用逻辑分析仪或数据时间戳验证。

`i2cread` 在 `iic.c` 中执行“写寄存器地址 → 重启 → 读 N 字节”，最后一个字节发送 NACK。它当前无论 ACK 是否成功都返回 `0x00`，所以 `if (!i2cread(...))` 实际上永远进入成功分支。可靠实现应让 `I2C_SendByte` 的 NACK 向上传递，并在失败时丢弃该帧、释放互斥锁和设置传感器故障标志。

## 3. 陀螺仪零偏和噪声

`MPU6050_Offset` 的陀螺分支累加 100 个静止样本：

```c
GYRO_X += gyro.x;
...
offsetGyro.x = GYRO_X / count_gyro;
```

均值可降低白噪声方差（约降为原来的 (1/N)），却不能消除温度漂移或振动造成的相关误差。建议记录 `Temperature` 与零偏，在多个温度点拟合一阶/二阶模型；飞行中仅在检测到“静止”（角速度和加速度同时稳定）时慢速更新，而不是无条件学习。

低通滤波的一阶离散形式为

\[
y_k=\alpha y_{k-1}+(1-\alpha)x_k,
\qquad \alpha=e^{-2\pi f_c\Delta t}.
\]

截止频率 (f_c) 应低于控制带宽但高于期望机动频率；滤波会引入相位延迟，必须在 PID 设计中计入。

## 4. HMC5883L 数据格式和航向

HMC5883L 的寄存器顺序是 X_MSB/LSB、Z_MSB/LSB、Y_MSB/LSB，`GY86_Read` 正确地把字节重排为 `mag.x/y/z`：

```c
mag.x = (dataBuf[0] << 8) | dataBuf[1];
mag.y = (dataBuf[4] << 8) | dataBuf[5];
mag.z = (dataBuf[2] << 8) | dataBuf[3];
```

但随后的符号处理存在问题：目标类型是 `int16_t`，负数赋值后整数提升已经是负值，`mag.x > 0x7fff` 不会成立；若先以 `uint16_t` 组包，再转换为 `int16_t`，也不应再减 `0xffff`（正确的补码回绕量是 `2^16=0x10000`）。建议使用明确函数：

```c
static int16_t be_i16(uint8_t hi, uint8_t lo) {
    return (int16_t)(((uint16_t)hi << 8) | lo);
}
```

`HMC5883L_Init` 将输出速率设为约 75 Hz、量程设为 ±1.3 Ga、连续测量。姿态任务约每 1 ms 读取一次，但磁力计并不会每次产生新样本；应读取状态寄存器或使用时间戳，重复样本时只沿用上一有效值。

## 5. 硬铁/软铁校准

理想磁场在不同朝向的端点落在球面：

\[
\|\mathbf m\|=B_0.
\]

硬铁磁场使球心平移，软铁材料使球变成椭球。工程模型为

\[
\mathbf m_c=A(\mathbf m_{raw}-\mathbf b),
\]

其中 `b` 是椭球中心，`A` 是 3×3 软铁校正矩阵。采集全姿态“画八字”数据，最小化

\[
\sum_i(\|A(\mathbf m_i-\mathbf b)\|-B_0)^2
\]

即可离线拟合；将结果写入 flash 时同时保存单位和传感器量程。仅做 `invSqrt(mx²+my²+mz²)` 只能消除量纲，不能消除椭球偏差。

倾斜补偿航向应先用姿态矩阵把磁场投影到水平面，再 `atan2`：

\[
\psi=\operatorname{atan2}(m_E,m_N).
\]

仓库 `Quat_Init` 假设 roll、pitch 为 0，直接用磁力计求 `initYaw`，所以必须水平放置启动；任意倾斜启动会产生系统性航向误差。

在一个常见的 NED/右手约定下，可先由重力估计倾角：

```c
roll  = atan2f(ay, az);
pitch = atan2f(-ax, sqrtf(ay*ay + az*az));
mx_h = mx*cosf(pitch) + mz*sinf(pitch);
my_h = mx*sinf(roll)*sinf(pitch)
     + my*cosf(roll) - mz*sinf(roll)*cosf(pitch);
yaw = atan2f(-my_h, mx_h);
```

这里的正负号只适用于所声明的轴向；本仓库的 `docs/九轴数据变化.txt` 对 pitch/roll 方向有自己的记录，移植前应把公式中的轴交换和符号逐项对照。更稳妥的做法是直接用 `q` 的旋转矩阵，将 `m_c` 变换到导航系后取北/东分量，避免手写多个特殊情况。

## 6. 与 AHRS 的融合接口

`Attitude_Update` 将归一化磁场与重力方向做叉乘误差，磁场主要约束 yaw，重力主要约束 roll/pitch。加速度模长偏离 1 g（电机振动、平移加速）时应降低重力权重；磁场模长偏离环境基准或突变时应停用磁校正，否则会把干扰解释成真实旋转。

读取、校准、滤波的推荐顺序是：

```text
I2C 原始帧 → 字节/补码解析 → 轴交换 → 零偏/比例校准
→ 单位换算 → 异常门限 → 低通（必要时陷波）→ AHRS
```

不要在 `Attitude_Update` 之后才修正轴向；那会同时污染四元数和控制器符号。

## 7. 并发、故障与验收

`Task_Angel`（1 tick）、`Task_COM`（10 tick）和 `Task_Height` 都访问共享传感器变量。I²C 事务由 `IICMutex` 保护，但共享结构体本身没有版本号或临界区；可使用“写入缓冲 A、完成后交换指针”的双缓冲。若 I²C 失败，应保留上次有效值并报告状态，而不是把未初始化的 `dataBuf` 送入归一化函数。

## 8. 相关气压通道的代码状态

虽然本题重点是陀螺仪和地磁，仓库的 `Task_Height` 也会调用 `GY86_Read(TEMP_PRESS)`。`GY86.c` 实现了 MS5611 的 PROM 读取、温度二阶补偿和压力计算，但 `BSP_Init` 中的 `MS561101BA_Init()` 被注释掉；在这种配置下 `Cal_C[]` 可能尚未填充，压力和 `K_PRESS_TO_HIGH` 不可信。`MS561101BA_Do_Conversion` 每次转换会 `OSTimeDly(9)`，而温度/压力函数在转换后又各自延时 9 tick；连续调用一次温度和一次压力实际可能阻塞约 36 ms，与高度任务的 1 ms 期望周期不一致。启用高度前应先初始化传感器、检查 CRC、按数据手册安排转换/读取时序，并把高度任务降到传感器实际输出率。

## 9. 验收和故障注入

验收应包括：静止 60 s 的角速度均值、温度扫描下的零偏曲线、每轴 ±90° 旋转的符号、磁力计三维椭球拟合残差，以及断开传感器时系统能否安全降级。电机和大电流线束会改变磁场，磁传感器应远离 ESC、电源线并固定安装。故障注入时可拔掉 I²C 线、强制 NACK、遮挡磁场，确认算法保持上次有效状态、报告故障且不会把电机推到危险转速。

## 10. 量程、采样率与单位的逐步核算

MPU6050 的陀螺量程由 `GYRO_CONFIG=0x18` 的 FS_SEL 位决定为 ±2000°/s，16 位 ADC 的灵敏度为
`2^15/2000=16.4 LSB/(°/s)`。例如原始值 `164` 表示 `10°/s`，代码换算为

```text
164 * 0.0610351 = 10.000 °/s
10 * π/180       = 0.174533 rad/s
```

`SMPLRT_DIV=0` 时，若 DLPF 已打开，内部采样率通常为 1 kHz；实际输出频率仍应以芯片数据手册和时间戳为准。DLPF 配置 `0x06` 会降低带宽和噪声，同时增加群延迟；如果姿态任务按 1 ms 更新而滤波器延迟数毫秒，PID 的相位裕度必须重新评估。每次改变量程、DLPF 或采样分频，都应重新做零偏和噪声标定，不能复用旧的 LSB 参数。

陀螺白噪声可通过均值降低，但均值窗口不能跨越真实旋转。对静止序列 `ω[k]`，长度为 `N` 的均值方差约为 `σ²/N`；偏置不稳定和温漂不服从这一缩减规律。可用 Allan 方差量化不同时间尺度：

\[
\sigma_A^2(\tau)=\frac{1}{2(M-1)}
\sum_{j=0}^{M-2}(\bar\omega_{j+1}(\tau)-\bar\omega_j(\tau))^2.
\]

在多个 `τ` 上画对数曲线，白噪声、偏置不稳定和随机游走的斜率不同；这比单凭“100 个样本看起来稳定”更能决定校准窗口和在线滤波截止频率。

## 11. HMC5883L 补码与轴序的可执行检查

HMC5883L 的寄存器顺序是 `X(MSB,LSB), Z(MSB,LSB), Y(MSB,LSB)`，所以源码先读取 `x、y(字节4/5)、z(字节2/3)`。补码解析应先组合成 `uint16_t`，再转换为 `int16_t`：

```c
static int16_t be_i16(uint8_t hi, uint8_t lo)
{
    uint16_t word = ((uint16_t)hi << 8) | (uint16_t)lo;
    return (int16_t)word;
}

mag.x = be_i16(dataBuf[0], dataBuf[1]);
mag.z = be_i16(dataBuf[2], dataBuf[3]);
mag.y = be_i16(dataBuf[4], dataBuf[5]);
```

测试向量 `0x00 0x64` 应为 `+100`，`0xFF 0x9C` 应为 `-100`，`0x80 0x00` 应为 `-32768`。当前代码把结果先放入 `int16_t`，再判断 `>0x7fff`，负值永远不会满足条件；即使改成无符号，减 `0xffff` 也会把 `0x8000` 算成 `-32767`，正确的补码回绕是 `0x10000`。这类错误会让磁场椭圆中心和 yaw 偏置随方向跳变。

HMC 配置 `CONFIG_A=0x18` 选择约 75 Hz 输出。姿态任务每 1 ms 读取一次时，连续读到的 13 次左右可能是同一个样本；应读取状态寄存器 `0x09` 的 `RDY` 位或记录“上次新样本时间”，将 `mag_valid` 和 `mag_age` 传给 AHRS。重复样本可以保持不变，但不能把它们当成 1 kHz 独立观测来估计噪声。

## 12. 硬铁、软铁与倾斜补偿的数学链路

理想磁场端点满足球面约束 `||m||=B₀`。附近电流和铁磁件造成硬铁平移 `b`，结构材料造成软铁线性变换 `A`：

\[
m_c=A(m_{raw}-b).
\]

至少应采集覆盖三维方向的“画八字”数据，拟合 `b` 和对称正定的 `A`；只减去三轴均值不能修复椭圆轴比。拟合后检查校正点云的协方差特征值是否接近相等，并记录 `B₀`、温度和安装位置。

磁力计只能测到地磁方向，机体倾斜时水平投影必须先恢复到导航系。若 `R_NB` 是代码约定的机体到导航矩阵：

```c
Float_t mn = mat3_mul_vec(R_NB, m_calibrated);
float yaw_mag = atan2f(mn.y, mn.x);  // 具体 N/E 顺序按坐标约定
yaw_mag += declination_rad;          // 磁偏角，需归一化到 [-π,π]
```

不要把磁倾角的 z 分量直接当 yaw；`Quat_Init` 目前固定 `roll=pitch=0`，所以必须水平启动，或者先用加速度估计倾角再做上述旋转。最终航向还要区分磁北与真北：当地磁偏角不写入代码时，长期稳定不代表指向地理北。

## 13. I²C 事务、故障标志和任务接口

软件 I²C 的 `I2C_SendByte()` 已经返回 ACK/NACK，但 `i2cread()` 和 `i2cwrite()` 无条件返回 `0x00`。建议让错误一路传播，并在所有路径释放互斥锁：

```c
bool read_mpu_frame(uint8_t *buf)
{
    INT8U err;
    bool ok = false;
    OSMutexPend(IICMutex, 0, &err);
    if (err == OS_NO_ERR && i2cread(MPU6050_Addr_Real,
                                    MPU6050_ACCEL_XOUT_H, 14, buf) == 0)
        ok = true;
    OSMutexPost(IICMutex);        // 成功/失败都释放
    return ok;
}
```

采样结果建议带结构化元数据：`sequence、timestamp、gyro_valid、acc_valid、mag_valid`。姿态任务只消费完整快照；通信任务发送快照副本，避免直接读取正在被 I²C 任务写入的全局 `mag/gyro/acc`。连续 `N` 次读取失败后，应进入传感器故障状态，把电机输出降到安全值，而不是继续积分旧数据。

## 14. 与 MS5611 高度通道的交叉影响

虽然本挑战不要求实现高度计，但 `Task_Height` 与姿态任务共享 I²C 总线。`BSP_Init()` 中 `MS561101BA_Init()` 被注释，而 `Task_Height` 仍调用转换函数；`Cal_C[]` 未初始化时，压力计算没有物理意义。源码低温补偿分支的 `SENS2 = SENS + 5.5f * Aux` 还应对照数据手册核查，标准公式通常是对 `SENS2` 增加 `5.5*Aux`，不能把原始 `SENS` 整项重复加入。每次 OSR=4096 转换需要等待约 9 ms，温度和压力连续读取会阻塞姿态所需的总线时隙；应让高度任务按传感器输出率运行，并在共享总线上设置明确的超时。

验收顺序建议为：先用固定磁场和测试字节验证解析，再做静止陀螺 Allan 分析，接着做三维椭球校准和 ±90° 倾斜补偿，最后才把电机、电源线和气压计加入系统。这样可以把“传感器坐标错误、磁干扰、总线时序错误、融合算法错误”分离定位。
