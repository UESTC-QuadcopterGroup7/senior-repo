# 挑战 6：梯度下降及数据处理

**代码定位：** 仓库目前没有梯度下降函数；数据采集入口是 [`Project/APP/main.c`](../../Project/APP/main.c#L102) 的 `Task_COM`，串口编码在 [`Project/APP_FUNC/usart.c`](../../Project/APP_FUNC/usart.c#L204)，姿态误差在 [`Project/APP_FUNC/IMU.c`](../../Project/APP_FUNC/IMU.c#L299)。

## 1. 梯度下降解决什么问题

梯度下降不是“滤波器名称”，而是一类迭代优化方法。给定参数向量 θ 和代价函数 J(θ)，在当前点沿负梯度方向移动：

\[
\theta_{k+1}=\theta_k-\mu_k\,\mathrm{grad}J(\theta_k),
\qquad \mathrm{grad}J=\left[\frac{\partial J}{\partial\theta_1},\ldots,\frac{\partial J}{\partial\theta_n}\right]^T.
\]

因为方向导数满足 `dJ/dε = gradJᵀd`，取 `d=-gradJ` 能在足够小的步长 μ 下最快降低一阶近似的代价。若目标函数为二次型 `J=1/2 θᵀHθ-bᵀθ`，稳定条件近似为 `0<μ<2/λmax(H)`；数据尺度差异大时，最大的特征值会迫使步长极小，这就是归一化的重要原因。

## 2. 本仓库中“已实现”和“未实现”的边界

当前源码没有名为 `GradientDescent` 的函数，也没有真正保存梯度参数。`IMU.c` 注释掉的高度惯性滤波和 `Attitude_Update` 的 PI 校正不是梯度下降。与本挑战最接近的两个位置是：

1. `Attitude_Update` 用方向误差（叉乘）修正角速度；它是 Mahony 风格的反馈积分，不是显式最小二乘优化。
2. `Height_Update` 的注释代码用固定权重融合气压和加速度；这是互补/惯性滤波，不是根据代价函数迭代参数。

因此，报告应把梯度下降作为“标定和算法改进方案”，不要声称仓库已经实现该算法。

## 3. 用梯度下降做加速度计标定

设原始数据为 `a_i`，待估参数包含偏置 `b` 和比例 `s`：

\[
\hat{\mathbf a}_i=\operatorname{diag}(s_x,s_y,s_z)(\mathbf a_i-\mathbf b).
\]

静止样本的物理约束是模长等于 `g_raw=8192`：

\[
r_i(\theta)=\|\hat{\mathbf a}_i\|-g_{raw},
\qquad J(\theta)=\frac{1}{2N}\sum_i r_i^2.
\]

令 `u_i = a_hat_i / ||a_hat_i||`，则对偏置的解析 Jacobian 为

\[
\frac{\partial r_i}{\partial b_x}=-s_xu_{ix},
\quad
\frac{\partial r_i}{\partial s_x}=u_{ix}(a_{ix}-b_x),
\]

其余分量同理，`gradJ=(1/N)Σ r_i grad r_i`。每轮遍历缓存样本，计算代价和梯度，然后更新参数；不要在迭代中重新从 I²C 读取，因为传感器状态会改变目标函数。

```c
for (i = 0; i < sample_count; ++i) {
    model_acc(theta, raw[i], &pred);
    r = norm3(pred) - 8192.0f;
    jacobian_acc(theta, raw[i], jac);
    for (j = 0; j < PARAMS; ++j)
        grad[j] += r * jac[j];
}
for (j = 0; j < PARAMS; ++j)
    theta[j] -= learning_rate * grad[j] / sample_count;
```

六个面（±x、±y、±z）才能让偏置和比例充分可观测；只在水平面采样时，某些参数方向会共线，梯度虽能下降却不代表标定正确。

### 一维例子理解步长

对 `J(θ)=1/2(θ-3)^2`，梯度是 `θ-3`。从 θ₀=0 出发，μ=0.5 时序列为 1.5、2.25、2.625……，单调趋近 3；μ=1.9 时仍振荡收敛，μ=2.1 时发散。真实标定问题只是把一个标量换成多维、带噪声的参数，故必须观察代价曲线，而不能只凭一次输出判断收敛。

## 4. Madgwick 中的梯度下降

Madgwick 把四元数 q 当作参数，令加速度/磁场参考向量的残差为 `f(q)`。使用 Jacobian `Jf` 得 `gradf=Jfᵀf`，再计算

\[
\dot q=\frac12q\otimes\omega-\beta\frac{\mathrm{grad}f}{\|\mathrm{grad}f\|}.
\]

这是一阶梯度修正，随后按时间步积分和归一化。仓库的 `Attitude_Update` 用 `ex/ey/ez` 反馈角速度（`Kp=2.0f`、`Ki=0.005f`），可以看成在旋转流形上的另一种误差下降；不能把 `Kp` 直接当作 Madgwick 的 β，二者量纲和稳定性含义不同。

## 5. 步长、收敛和鲁棒性

固定 μ 简单但对不同温度、姿态和数据尺度敏感。推荐：

- 输入减均值并按量程归一化；
- 用回溯线搜索，新代价上升时缩小 μ；
- 对残差使用 Huber 损失，避免单个振动尖峰主导梯度；
- 设置 `MAX_ITER`、梯度范数阈值、参数边界和 NaN 检查；
- 训练样本与验证样本分离，报告最终残差而非只报告迭代次数。

若 Hessian 条件数很大，可改用动量、AdaGrad 或 Levenberg–Marquardt。Cortex-M4 上不建议在 1 ms 姿态任务中做大矩阵优化；离线拟合参数，在线只做矩阵乘法。

## 6. 传感器数据处理的数学细节

### 6.1 采样和时间戳

`Task_Angel` 使用 `OSTimeDly(1)`，`Get_AHRS_Time()` 从 TIM2 读计数并返回 `now/2000000.0f`（即半周期）。任务调度抖动会改变 Δt，梯度和积分都应使用真实时间戳；应记录 `t_k` 而非根据数组下标假设等间隔。

### 6.2 滤波

一阶低通为

\[
y_k=\alpha y_{k-1}+(1-\alpha)x_k,
\quad \alpha=e^{-\Delta t/\tau}.
\]

电机转速谐波可用二阶陷波器，但要先从 `Send_Senser` 的原始数据做 FFT 确认频率。滤波器状态应在传感器复位/重新校准时清零。

### 6.3 异常值和权重

加速度模长偏离 1 g、磁场模长偏离环境基准或 I²C 校验失败时，把该观测权重降为 0，而不是把异常值硬塞进 AHRS。权重可以连续化，例如 `w_a=exp(-((||a||-g)/σa)^2)`。

### 6.4 量化、溢出和定点实现

STM32 工程中原始传感器是 `int16_t`，累加校准样本使用 `int32_t`（见 `ACC_X`、`GYRO_X`），这是避免 100 次累加溢出的必要措施；若扩大窗口或加入比例矩阵，仍要估算最坏值。梯度参数和代价通常用 `float`，要避免把很小的梯度截断成整数。若必须使用定点数，应为每个参数选择独立 Q 格式，并在乘法后显式右移和饱和。

## 7. 与串口数据记录的代码问题

`main.c` 的 `Task_COM` 调用 `Send_5_float(0xF2, expRoll, ...)`。但 `usart.c` 中把每个 `float` 隐式赋给 `vs16 _temp`，再发送两个字节：

```c
vs16 _temp;
_temp = f1;
sendBuf[_cnt++] = BYTE1(_temp);
sendBuf[_cnt++] = BYTE0(_temp);
```

这不是 IEEE-754 浮点传输，而是截断为 16 位整数；离线梯度分析会丢失小数和单位。应明确采用“缩放整数”（如角度×100）或发送 4 字节 `float`，并在协议文档中写端序、缩放因子和校验规则。`Send_Senser` 同样发送原始 `int16_t`，适合记录，但要附带采样时间和有效标志。

## 8. 推荐实验流程

1. 固定机体，采集六面各 500 个加速度样本及温度。
2. 离线运行梯度下降，画 `J(k)`、各参数和验证集残差。
3. 将最终偏置/比例写入配置，比较校准前后的模长标准差。
4. 回放同一数据，确认 AHRS 姿态误差下降且无 NaN。
5. 再在无桨硬件上验证，逐步增加振动和机动幅度。

这样既能说明梯度下降的数学原理，也能清楚区分仓库现有实现、拟议算法和数据链路中的实际限制。

## 9. 梯度下降、Gauss—Newton 与 Madgwick 的关系

三者都出现“沿误差方向修正”的外观，但近似对象不同：

| 方法 | 更新量 | 曲率信息 | 适合本项目的场景 |
| --- | --- | --- | --- |
| 梯度下降 | `-μ J' r` | 不使用 | 大数据集、低内存、离线标定 |
| Gauss—Newton | `Δ`，解 `J'JΔ=-J'r` | 使用一阶 Jacobian 的曲率近似 | 参数数量较少、希望快速收敛的标定 |
| Madgwick | `-β (J_q' f)/||J_q'f||` | 只保留归一化梯度方向 | 在线四元数姿态修正 |

对二次目标 `J=1/2(θ-θ*)'H(θ-θ*)`，梯度下降的误差传播为
`e_{k+1}=(I-μH)e_k`。只有所有特征值满足 `|1-μλ_i|<1` 才收敛，即
`0<μ<2/λ_max(H)`；病态数据中 `λ_max/λ_min` 很大时会出现“某个方向已经振荡，另一个方向还没走到位”。Gauss—Newton 或参数白化可以缓解这一问题，但都不能弥补姿态样本不可观测。

## 10. 一次迭代的数值算例

考虑只有一个比例参数 `s` 的加速度模长残差：测量 `a=8300`、目标 `g=8192`、初值 `s=1`，则 `r=108`。若代价 `J=1/2r²`，

\[
\frac{\partial r}{\partial s}=a=8300,\qquad
\frac{\partial J}{\partial s}=r\,a=896400.
\]

直接用 `μ=10^{-4}` 会把 `s` 改成 `-88.64`，立即发散；把输入先缩放为 `a/g` 后，导数约为 1，`μ=0.01~0.1` 才有可解释的步长。这说明学习率没有脱离单位的独立意义：必须先决定参数和观测的尺度，再比较不同数据集的 `μ`。

实际实现可使用归一化输入 `\tilde a=a/g_raw`、对数比例参数 `s_j=exp(η_j)`（天然保证正值），并把偏置限制在传感器合理范围。每轮更新后同时记录 `cost、||grad||、||delta||、有效样本数`，这样能区分“梯度很小的真正收敛”和“所有样本被门控掉”的假收敛。

## 11. 可回放的主机端标定代码

下面示例用批量梯度下降拟合对角比例和偏置；输入 `samples` 是已经从串口解码的 raw LSB，训练和验证数据应在采集时分开：

```python
import numpy as np

def fit_acc(samples, g=8192.0, steps=2000, lr=0.02):
    x = np.asarray(samples, dtype=np.float64) / g
    b = np.zeros(3); eta = np.zeros(3)       # scale = exp(eta)
    for k in range(steps):
        s = np.exp(eta)
        y = (x - b) * s
        rho = np.linalg.norm(y, axis=1)
        rho = np.maximum(rho, 1e-12)
        r = rho - 1.0
        u = y / rho[:, None]
        grad_b = np.mean((-u * s) * r[:, None], axis=0)
        grad_eta = np.mean((u * y) * r[:, None], axis=0)
        old = 0.5 * np.mean(r*r)
        step = lr
        while step > 1e-8:
            nb, ne = b - step*grad_b, eta - step*grad_eta
            nr = np.linalg.norm((x-nb)*np.exp(ne), axis=1)-1.0
            if 0.5*np.mean(nr*nr) <= old: break
            step *= 0.5
        b, eta = nb, ne
        if np.linalg.norm(np.r_[grad_b, grad_eta]) < 1e-8: break
    return b*g, np.exp(eta)
```

这里把 `b` 存成 g 单位，返回时乘回 LSB；若要加入轴间耦合，把 `y=(x-b)@M.T`，并按 `∂ρ/∂M_{jk}=u_j(x_k-b_k)` 填充梯度。代码中的 `grad_b`/`grad_eta` 只适用于对角模型，不能误用于完整 3×3 矩阵。

## 12. 串口帧的真实格式与解析

发送函数统一构造：

```text
AA | 05 | AF | frame | length | payload[0..length-1] | checksum
```

`checksum = (所有前置字节之和) & 0xff`。`Send_Senser()` 的 payload 是 9 个 `int16_t`，长度 18，整帧 24 字节；`Send_5_float()` 名字虽然写着 float，实际每个参数先转换为 `vs16`，payload 只有 10 字节，整帧 16 字节。`BYTE1` 到 `BYTE0` 在当前小端 ARM 上按高字节在前发送，但宏本身依赖机器端序，跨平台解析必须明确使用大端格式：

```python
import struct

def decode(frame):
    if frame[0:3] != bytes((0xAA, 0x05, 0xAF)):
        raise ValueError("header")
    n = frame[4]
    if len(frame) != n + 6 or (sum(frame[:-1]) & 0xff) != frame[-1]:
        raise ValueError("length/checksum")
    payload = frame[5:-1]
    if frame[3] == 0x02:
        return struct.unpack(">9h", payload)
    if frame[3] in (0xF2, 0xF3):
        return struct.unpack(">5h", payload)
    return payload
```

浮点到 `int16_t` 的隐式转换会截断小数，且超出范围时不应依赖编译器行为。建议协议改成明确的缩放整数（例如角度×100）或 4 字节 IEEE-754，并在帧中增加 `timestamp_us、dt_us、valid_flags`；否则离线梯度会把量化误差和时间抖动混进传感器模型。

## 13. 在线数据处理的顺序与门控

一条可审计的数据管线应保持以下顺序：

```text
接收字节 → 帧同步/长度/校验 → 端序解码 → 单位换算
→ 时间戳去抖 → 零偏/比例校正 → 异常值门控 → 滤波/优化
```

门控前不要先把全零帧代入 `invSqrt`；对加速度可用 `| ||a||-g | < 3σ`，对磁场可用椭球校正后的模长和突变率，I²C/串口校验失败则权重直接置零。滤波器的状态必须按传感器重启或重新校准事件清空，否则旧状态会伪造一段“平滑但错误”的数据。

对于批量优化，按时间或飞行段切分训练/验证集，不能随机打散同一连续窗口；否则相邻样本泄漏会虚高精度。报告应给出校准前后验证集 RMS、95% 分位误差、被拒绝样本比例和迭代耗时，而不是只给最终参数。

## 14. 在 Cortex-M4 上的落地边界

梯度下降每轮需要遍历全部样本，复杂度约为 `O(NP)`；`N` 为缓存样本数、`P` 为参数数。飞控姿态任务只有约 1 ms 时间片，不应在其中执行大批量优化。可行的分层方案是：PC 离线求 `b、M`，固件启动时从 Flash 读取并做一次 CRC 校验；在线只完成 3×3 矩阵乘法、向量归一化和 AHRS 更新。若确实需要在线自适应，只在检测到静止的低优先级任务中用小批量、限步长更新，并把结果双缓冲后一次性发布给姿态任务。
