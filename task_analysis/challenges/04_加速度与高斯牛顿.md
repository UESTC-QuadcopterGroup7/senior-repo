# 挑战 4：姿态数据采集、加速度计处理与高斯—牛顿迭代

**代码定位：** [`Project/APP_FUNC/IMU.c`](../../Project/APP_FUNC/IMU.c#L56) 的 `MPU6050_Offset`、[`IMU.c`](../../Project/APP_FUNC/IMU.c#L146) 的 14 字节读取；设备寄存器配置在 [`Project/APP_FUNC/GY86.c`](../../Project/APP_FUNC/GY86.c#L23)。

## 1. 加速度计测到的到底是什么

理想加速度计测量的是比力（specific force），可写成

\[
\mathbf f^B=R_{BN}(\mathbf a^N-\mathbf g^N)+\mathbf b_a+\mathbf n_a,
\]

其中 `aᴺ` 是机体质心线加速度，`gᴺ` 是重力，`bₐ` 是零偏，`nₐ` 是噪声。静止时 `aᴺ=0`，所以输出的模长应接近 `g=9.80665 m/s²`，方向取决于“z 向上/向下”和芯片定义。不能把静止读数当成 0；它包含重力（更准确地说是重力的反向比力）。

本项目 MPU6050 配置为 ±4 g，灵敏度 `8192 LSB/g`。因此原始静止模长约为 8192，而不是 9.8。单位换算为

\[
a_{m/s^2}=\frac{a_{raw}}{8192}\times9.80665.
\]

## 2. 采集链路和字节解析

`GY86_Read(ACC_GYRO_MAG)` 在 `Project/APP_FUNC/IMU.c` 中连续读取从 `MPU6050_ACCEL_XOUT_H (0x3B)` 开始的 14 字节：AX、AY、AZ、温度、GX、GY、GZ。连续读取保证同一采样时刻的数据一致；代码片段为：

```c
if (!i2cread(MPU6050_Addr_Real, MPU6050_ACCEL_XOUT_H, 14, dataBuf)) {
    acc.x = ((((int16_t)dataBuf[0]) << 8) | dataBuf[1]) - offsetAcc.x;
    acc.y = ((((int16_t)dataBuf[2]) << 8) | dataBuf[3]) - offsetAcc.y;
    acc.z = ((((int16_t)dataBuf[4]) << 8) | dataBuf[5]) - offsetAcc.z;
}
```

`BSP_Init` 先调用 `MPU6050_Init`，其中 `SMPLRT_DIV=0`、数字低通配置 `0x06`、加速度量程 `0x08`。这些寄存器决定采样率、带宽和比例，标定数据必须与它们绑定保存。I²C 总线由 `IICMutex` 保护，但 `BSP_Init` 创建互斥锁之前会初始化设备；初始化阶段不应并发访问。

## 3. 当前零偏校准的数学意义

`MPU6050_Offset` 为每一轴计算静止均值：

```c
ACC_X += acc.x;  ACC_Y += acc.y;  ACC_Z += acc.z;
...
offsetAcc.x = ACC_X / count_acc;
offsetAcc.y = ACC_Y / count_acc;
offsetAcc.z = ACC_Z / count_acc - 8192;
```

计数器从 1 开始，在达到 101 时回退到 100，因此实际累加 100 个样本。假设机体水平、静止且 z 轴正好承受 +1 g，前两轴均值就是偏置，z 轴均值减 8192 后才是偏置。这个方法只估计“一个姿态下的偏置”，没有估计比例误差、轴不正交和安装倾斜；机体换方向或量程改变后必须重新标定。

校准状态由 `Open_Calib` 置 1，由 `Calib_Status` 的按位或结果判断是否完成。`main.c` 在校准完成前不调用姿态和 PID，但仍会发送原始数据，便于观察静止质量。

## 4. 六面体标定模型

更完整的模型可写为

\[
\mathbf a_c=M(\mathbf a_{raw}-\mathbf b),
\]

其中 `b=[bx,by,bz]ᵀ` 为偏置，`M` 包含每轴比例和轴间耦合。采集六个已知静止姿态（+x、−x、+y、−y、+z、−z），每个姿态的真实比力向量为 `fᵢ`，理想约束为

\[
r_i(\theta)=\|M(\mathbf a_i-\mathbf b)\|-g=0.
\]

若同时记录姿态矩阵 `Rᵢ`，也可使用三维残差

\[
\mathbf r_i=R_iM(\mathbf a_i-\mathbf b)-\mathbf g_i,
\]

信息更多但要求参考姿态可靠。把所有残差堆成 `r(θ)`，参数例如

\[
\theta=[b_x,b_y,b_z,s_x,s_y,s_z,m_{xy},m_{xz},m_{yz}]^T.
\]

## 5. 高斯—牛顿推导

在第 k 次迭代附近一阶展开：

\[
r(\theta_k+\Delta)\approx r_k+J_k\Delta,
\qquad J_{ij}=\frac{\partial r_i}{\partial\theta_j}.
\]

令平方误差 `F=1/2 rᵀr` 最小，得到正规方程

\[
(J^TJ)\Delta=-J^Tr,
\qquad \theta_{k+1}=\theta_k+\lambda\Delta,
\]

其中 `0<λ≤1` 是阻尼步长。直接求 `(JᵀJ)⁻¹` 会放大病态问题，嵌入式上可离线用 QR/SVD；若必须在线，使用 Cholesky 或 Levenberg–Marquardt：

\[
(J^TJ+\lambda_d I)\Delta=-J^Tr.
\]

### 一个可移植的伪代码

```c
for (iter = 0; iter < MAX_ITER; ++iter) {
    residual_and_jacobian(theta, samples, r, J);
    solve_damped_normal(J, r, delta);  // 不显式求逆
    limit_step(delta);
    theta += delta;
    if (norm(delta) < EPS || cost_increase()) break;
}
```

若没有解析 Jacobian，可用中心差分

\[
J_{:,j}\approx\frac{r(\theta+h e_j)-r(\theta-h e_j)}{2h},
\]

但要平衡截断误差与浮点舍入，且每次调用不能触发传感器 I²C 读写，应对固定数据集计算。

### 由模长残差得到的一个 Jacobian 列

令 `v=M(a-b)`、`ρ=||v||`，则 `r=ρ-g` 的微分为
`dr = (vᵀ/ρ) dM (a-b) - (vᵀ/ρ)M db`。若 `M=diag(sx,sy,sz)`，就有
`∂r/∂bx = -sx·vx/ρ`、`∂r/∂sx = vx·(ax-bx)/ρ`。这个推导说明：当某一姿态的 `vx` 接近 0 时，关于 `bx` 或 `sx` 的信息很少；六面、多姿态采样能改善 `JᵀJ` 的条件数。实际求解前应计算奇异值，发现最小奇异值过小时增加姿态样本，而不是盲目增加迭代次数。

如果每个样本噪声方差不同，可使用加权最小二乘：

\[
(J^TWJ)\Delta=-J^TWr,
\qquad W=\operatorname{diag}(w_1,\ldots,w_N).
\]

权重可由静止窗口的方差、温度稳定性和振动检测得到。报告中应同时给出偏置估计的单位（LSB 或 g）、比例因子、残差 RMS 和置信区间，避免只列出一组无法复现的数字。

## 6. 把标定结果接入现有代码

当前 `Acc_t` 是 `int16_t`，只适合保存原始值；建议增加浮点校正层：

```c
Float_t acc_g;
acc_g.x = (acc.x - bias.x) * scale.x;
acc_g.y = (acc.y - bias.y) * scale.y;
acc_g.z = (acc.z - bias.z) * scale.z;
```

然后将 `acc_g` 传给 AHRS，而不是继续把固定的 `offsetAcc` 当作完整标定。若保留整数接口，应明确舍入和溢出策略。校准参数要带量程、温度和固件版本，避免把 ±2 g 的参数误用于 ±4 g。

## 7. 数据质量、异常检测和代码风险

在进入 `Attitude_Update` 前建议检查：

```c
float norm2 = ax*ax + ay*ay + az*az;
if (norm2 < 1e-6f || fabsf(sqrtf(norm2) - 8192.0f) > ACC_GATE)
    use_acc = 0;  // 机动/振动时不修正重力方向
```

实际门限应按噪声和机动调试，不能固定照抄。当前代码存在几个必须在实验报告中说明的限制：

1. `offsetAcc.z` 硬编码 8192，只对当前量程和水平姿态成立。
2. 读失败时互斥锁只在成功分支 `OSMutexPost`，可能导致后续任务永久阻塞；应使用 `finally` 式路径无条件释放。
3. `acc`、`offsetAcc` 被多个任务共享，更新不是原子事务；可用临界区或双缓冲避免姿态任务读到半更新向量。

完成标定后，用六个姿态分别检查 `|a_c|` 的均值和标准差，并把原始/校正数据通过 `Send_Senser` 记录，才算证明高斯—牛顿结果真正改善了飞控输入。

## 8. 六面标定的闭式初值

高斯—牛顿不应从完全随机的参数开始。若只考虑每轴偏置 `b_j` 和比例 `s_j`，静止时把同一轴分别朝正、负方向放置，有

\[
a_j^+=b_j+\frac{g_{raw}}{s_j},\qquad
a_j^-=b_j-\frac{g_{raw}}{s_j}.
\]

因此可先用闭式公式得到

\[
b_j=\frac{a_j^++a_j^-}{2},qquad
s_j=\frac{2g_{raw}}{a_j^+-a_j^-}.
\]

例如 `g_raw=8192`、测得 `a_x^+=8300`、`a_x^-=-8100`，则 `b_x=100 LSB`、`s_x≈0.9990`。把 `8300` 校正为 `(8300-100)*0.9990≈8192`，再以此作为九参数模型的初值，通常比直接令 `b=0,s=1` 收敛更快。每一面应取一个静止窗口的均值，而不是使用单个瞬时样本。

## 9. 从残差到 Jacobian 的完整推导

令 `d_i=a_i-b`、`v_i=M d_i`、`ρ_i=\|v_i\|`，采用模长残差 `r_i=ρ_i-g_raw`。定义 `u_i=v_i/ρ_i`，则微分为

\[
dr_i=u_i^T(dM\,d_i-M\,db).
\]

这一个式子同时给出所有参数的导数：

\[
\frac{\partial r_i}{\partial b}=-M^Tu_i,
\qquad
\frac{\partial r_i}{\partial M_{jk}}=u_{ij}d_{ik}.
\]

当 `M=diag(sx,sy,sz)` 时，就退化为文档前面列出的 `-s_j u_j` 和 `u_j(a_j-b_j)`。若使用带已知参考方向的三维残差 `\mathbf r_i=M(a_i-b)-f_i`，Jacobian 更简单：偏置块是 `-M`，对 `M_{jk}` 的列只有第 `j` 个分量为 `a_{ik}-b_k`。三维残差包含方向信息，但需要可靠的六面参考姿态；模长残差对姿态标签不敏感，却需要更多不同方向才能让 `J^TJ` 满秩。

高斯—牛顿每轮实际上在解

\[
(J^TWJ+\lambda I)\Delta=-J^TWr,
\]

然后用线搜索选择 `α`，令 `θ_new=θ+αΔ`。`λ` 是阻尼，不应与姿态算法中的 `Ki` 或 Madgwick 的 `β` 混用。不要显式计算逆矩阵；在主机端用 QR/SVD，在 MCU 上若参数很少可用 Cholesky，并在分解失败时增大阻尼。

## 10. 与 `MPU6050_Offset` 的时间和整数语义

源码把 `count_acc` 设为 1 后立即 `return`，随后累计到 101 时得到 100 个有效样本（约 0.1 s，前提是姿态任务确实为 1 kHz）。`ACC_X/ACC_Y/ACC_Z` 使用 `int32_t`，避免 `int16_t` 累加溢出；若窗口扩大到数千点，仍需按最坏原始值估算 `N·32768` 是否超出 32 位范围。整数除法会截断偏置，建议在离线结果写回时保留浮点值，在线只在最后一步按“就近舍入”转换为 LSB。

现有代码的 `offsetAcc.z = mean_z - 8192` 把重力参考写死在 ±4 g 量程。更可维护的写法是由寄存器配置得到 `lsb_per_g`，并把安装姿态作为参数：

```c
typedef struct {
    float bias[3];
    float scale[3];
    float lsb_per_g;
} AccCal;

static Float_t acc_calibrate(const AccCal *c, Acc_t raw)
{
    Float_t out;
    out.x = (raw.x - c->bias[0]) * c->scale[0] / c->lsb_per_g;
    out.y = (raw.y - c->bias[1]) * c->scale[1] / c->lsb_per_g;
    out.z = (raw.z - c->bias[2]) * c->scale[2] / c->lsb_per_g;
    return out;                 // 单位：g
}
```

姿态算法只应接收这里的浮点校正结果；若仍传 raw LSB，门控阈值、重力向量和高度积分会使用不同单位。

## 11. 一段可回放的高斯—牛顿实现框架

下面代码展示“固定数据集、计算残差/Jacobian、阻尼求解”的边界。`solve_linear` 代表一个不显式求逆的线性方程求解器；实际九参数模型可用 9×9 的 QR/Cholesky。

```c
enum { PARAMS = 9 };
float H[PARAMS][PARAMS], grad[PARAMS], delta[PARAMS];
for (int iter = 0; iter < 30; ++iter) {
    memset(H, 0, sizeof(H));
    memset(grad, 0, sizeof(grad)); // grad=J'Wr
    float cost = 0.0f;
    for (int i = 0; i < N; ++i) {
        float v[3], jac[PARAMS], r;
        model_and_jacobian(theta, samples[i], v, jac, &r);
        float w = robust_weight(r); // Huber 或固定权重
        cost += 0.5f * w * r * r;
        for (int j = 0; j < PARAMS; ++j) {
            grad[j] += w * jac[j] * r;
            for (int k = 0; k < PARAMS; ++k)
                H[j][k] += w * jac[j] * jac[k];
        }
    }
    for (int j = 0; j < PARAMS; ++j) H[j][j] += damping;
    for (int j = 0; j < PARAMS; ++j) grad[j] = -grad[j];
    solve_linear(H, grad, delta, PARAMS); // H*delta=-J'W r
    if (!finite_vector(delta) || norm(delta) > STEP_MAX) break;
    if (trial_cost(theta, delta) < cost) {
        axpy(theta, delta, 1.0f);
        damping *= 0.5f;
    } else {
        damping *= 10.0f;
    }
}
```

在 MCU 上不应在 1 ms 姿态任务中执行这段迭代；正确架构是 PC 端读取 `Send_Senser` 数据完成拟合，最后把 `bias/scale/M` 写入配置，固件每次采样只做一次矩阵乘法。

## 12. 验证指标和异常样本

标定报告至少应给出每个姿态的 `mean(||a_c||)`、标准差、最大误差和验证集 RMS。若某一面采样期间机体移动，模长残差会把线性加速度误认为比例误差；可以用窗口方差和 `||a||` 偏离门限剔除该窗口。高斯—牛顿出现 `J^TJ` 条件数很大时，优先增加姿态覆盖或降低参数自由度，不要仅增加迭代次数。I²C 失败样本必须带有效位，不能把全零数据当成“接近重力”的合法观测。
