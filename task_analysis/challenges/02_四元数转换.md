# 挑战 2：四元数与欧拉角的转换

**代码定位：** [`Project/APP_FUNC/IMU.c`](../../Project/APP_FUNC/IMU.c#L212) 的 `Quat_Init`、四元数积分和 `Angle_t` 输出；[`Project/APP_FUNC/IMU.h`](../../Project/APP_FUNC/IMU.h#L7) 的单位常量。

## 1. 四元数为什么适合飞控

用 `q=w+xi+yj+zk` 表示单位旋转时，只需 4 个数和一个约束

\[
\|q\|^2=w^2+x^2+y^2+z^2=1.
\]

相比 3×3 矩阵（9 个数），四元数占用少；相比欧拉角，它没有中间姿态的万向节锁。注意 `q` 与 `-q` 表示同一个旋转，因此四元数符号突然翻转不代表机体真的跳变，但会影响直接绘图和差分，记录时可保持与上一帧点积为正。

## 2. 代数运算和向量旋转

两个四元数乘法（Hamilton 约定）为

\[
q_1\otimes q_2=(w_1w_2-\mathbf v_1\cdot\mathbf v_2,
w_1\mathbf v_2+w_2\mathbf v_1+\mathbf v_1\times\mathbf v_2).
\]

共轭为 `q*=(w,-x,-y,-z)`，单位四元数的逆为 `q⁻¹=q*`。把向量写成纯虚四元数 `p=(0,v)`，旋转结果是 `p'=q⊗p⊗q*`。乘法顺序决定“机体系到导航系”还是反向变换，不能凭经验交换。

## 3. 角速度微分方程

陀螺仪提供机体系角速度 `ω=[gx,gy,gz]`（rad/s）。若使用本仓库“`q` 在左、角速度四元数在右”的乘法约定，可写

\[
\dot q=\frac12q\otimes(0,\boldsymbol\omega).
\]

展开为

\[
\begin{aligned}
\dot w&=-\tfrac12(xg_x+yg_y+zg_z),\\
\dot x&=\tfrac12(wg_x+yg_z-zg_y),\\
\dot y&=\tfrac12(wg_y-xg_z+zg_x),\\
\dot z&=\tfrac12(wg_z+xg_y-yg_x).
\end{aligned}
\]

显式 Euler 积分为 `q(k+1)=q(k)+q̇Δt`，单步局部截断误差为 `O(Δt²)`（累计全局误差为 `O(Δt)`）。仓库把 `Δt/2` 记为 `halfT`，所以更新式看起来没有显式的 `0.5`。

这也是为什么在高角速度或任务周期抖动时，使用指数映射得到的增量四元数更稳健。

## 4. 仓库实现逐行解释

`IMU.c` 的全局状态：

```c
float q0 = 1, q1 = 0, q2 = 0, q3 = 0;
float halfT = 0.0005f;
```

`q0` 是标量部，`q1/q2/q3` 是向量部。`Quat_Init` 先假设初始机体水平（`initRoll=initPitch=0`），利用 HMC5883L 计算 yaw，再用半角公式赋值：

```c
q0 = cos(roll/2)*cos(pitch/2)*cos(yaw/2)
   + sin(roll/2)*sin(pitch/2)*sin(yaw/2);
```

这里的变量注释把 `q1` 写成 Pitch、`q2` 写成 Roll；而 `Attitude_Update` 输出公式把 `q0*q2-q1*q3` 作为 roll 的正弦。说明“变量名/注释”不能单独作为轴序依据，必须用已知姿态矩阵和 `docs/九轴数据变化.txt` 做实测校准。

积分部分保存旧值，避免同一轮计算读到已更新分量：

```c
q0 = q0_last + (-q1_last*gx - q2_last*gy - q3_last*gz)*halfT;
q1 = q1_last + ( q0_last*gx + q2_last*gz - q3_last*gy)*halfT;
q2 = q2_last + ( q0_last*gy - q1_last*gz + q3_last*gx)*halfT;
q3 = q3_last + ( q0_last*gz + q1_last*gy - q2_last*gx)*halfT;
```

之后：

```c
norm = invSqrt(q0*q0 + q1*q1 + q2*q2 + q3*q3);
q0 *= norm; q1 *= norm; q2 *= norm; q3 *= norm;
```

归一化是必要的：积分舍入会使 `|q|` 缓慢偏离 1，进而使“旋转矩阵”不再正交。`invSqrt` 的位级类型双关在现代 C 中可能触发严格别名未定义行为；若升级编译器，应使用 `memcpy` 或 CMSIS 数学函数，并在输入不大于零时直接报错。

## 5. 四元数到欧拉角

本项目实际代码（`IMU.c` 约 338–341 行）是：

```c
angle.roll  =  asin(2.0f*(q0*q2 - q1*q3))*RAD_TO_ANGLE;
angle.pitch = -atan2(2.0f*(q0*q1 + q2*q3),
                     q0*q0-q1*q1-q2*q2+q3*q3)*RAD_TO_ANGLE;
angle.yaw   =  atan2(2.0f*(q0*q3 + q1*q2),
                     q0*q0+q1*q1-q2*q2-q3*q3)*RAD_TO_ANGLE;
```

`RAD_TO_ANGLE=57.2957795` 将弧度变为度。`asin` 的输入理论上在 [-1,1]，但浮点误差可能得到 1.0000001；应先执行 `constrain(s,-1,1)`。`atan2` 返回 [-π,π]，如果上位机需要连续航向，应做 unwrap，而不是简单滤波跨 ±180° 的跳变。

## 6. 欧拉角到四元数

对于同一 Z-Y-X 顺序，令 `cφ=cos(φ/2)`、`sφ=sin(φ/2)` 等：

\[
\begin{aligned}
w&=c_\phi c_\theta c_\psi+s_\phi s_\theta s_\psi,\\
x&=s_\phi c_\theta c_\psi-c_\phi s_\theta s_\psi,\\
y&=c_\phi s_\theta c_\psi+s_\phi c_\theta s_\psi,\\
z&=c_\phi c_\theta s_\psi-s_\phi s_\theta c_\psi.
\end{aligned}
\]

`Quat_Init` 的四行正是这一公式的实现，但初始 roll/pitch 被固定为 0，因此它只能用磁力计设定水平起始的偏航，不能恢复任意倾斜放置时的完整初始姿态。

还要检查初始航向的轴定义：在 roll/pitch 为 0 时，`Quat_Init` 的表达式退化为 `atan2(initMx, initMy)`，而许多罗盘约定使用 `atan2(My, Mx)`。两者相差 90° 或符号翻转并不一定是代码错误，可能来自 HMC5883L 板上轴向、磁北/地理北和 yaw 零点的定义；但必须在文档中明确，并用已知朝向标定偏角。若需要倾斜启动，应先由加速度求 roll/pitch，再对磁场做 tilt compensation，最后构造 q。

## 7. 与传感器单位和任务时序的关系

`GY86_Read` 在 `IMU.c` 中先把原始陀螺数据乘 `RAW_TO_RAD=0.0010653`，再传给 `Attitude_Update`；若误传 `RAW_TO_ANGLE`，角速度会大约放大 57.3 倍。`Task_Angel` 的 `OSTimeDly(1)` 只是让出一个 OS tick，真正的周期由 `TIM2` 的 `Get_AHRS_Time()` 测得。积分时应使用这一个周期，并在异常的大周期（任务被阻塞）时丢弃或限制该样本。

角度接口还存在周期性问题：`angle.yaw` 由 `atan2` 返回 −180° 到 +180°，例如从 179° 转到 −179° 时物理只转了 2°，直接做差却得到 −358°。若把 yaw 误差送入控制器，应使用 `wrap_pi`：`e = fmodf(e + 180, 360) - 180`，并注意 C 的负数 `fmodf` 需要额外修正。

## 8. 可复现实验和边界条件

用主机程序生成随机欧拉角（避开 pitch ±90°），执行“角度→q→角度”，误差应小于浮点容差；再比较两次旋转矩阵的 Frobenius 范数。上机检查：

- 静止时 `q0*q0+...+q3*q3` 是否接近 1；
- 纯 yaw 旋转是否只改变 `angle.yaw`；
- 传感器断线时是否避免用未更新的旧 q；
- 多任务访问 q/angle 时是否需要临界区或双缓冲。

### 一个可手算的 90° 例子

若按 `Attitude_Update` 的输出公式把 `q2` 视为 roll 分量，只绕 roll 正向旋转 90°，对应四元数应为
`q=(cos45°, 0, sin45°, 0)`；只绕 pitch 则应为 `q=(cos45°, sin45°, 0, 0)`。把导航系单位向量代入 `q⊗p⊗q*`，再代入 `angle.roll/pitch/yaw` 三个公式，应只出现一个约 90° 的角。这个例子能同时检验半角公式、乘法顺序、输出符号和角度单位，比只观察静止值更有区分度。

### 误差传播和工程选择

若四元数有小扰动 `δq`，归一化会把扰动投影回单位球面，但不会消除传感器噪声。由 `atan2` 求角度时，分母接近零会使角度对噪声非常敏感；控制器应使用 q 或旋转向量计算误差，显示层再转换成欧拉角。通信任务可以发送角度，`Task_PID` 则应避免用跨 ±180° 的 yaw 差值直接做 P 控制。

在代码评审中建议把四元数封装为结构体和函数（`quat_normalize`、`quat_to_matrix`、`quat_to_euler`），不要让 `q0…q3` 作为无类型全局变量被多个任务任意写入。这样可以在一个地方统一处理符号连续性、NaN 和坐标约定。

结论：转换公式必须和轴序、乘法约定、坐标方向成套使用；只复制一段常见公式而不核对本项目符号，会造成“角度看起来合理但 PID 方向错误”。

## 9. 轴角到四元数：为什么必须除以二

单位轴 `u` 绕自身旋转 `α` 的四元数为

\[
q_{u,\alpha}=\left(\cos\frac{\alpha}{2},\;u_x\sin\frac{\alpha}{2},\;u_y\sin\frac{\alpha}{2},\;u_z\sin\frac{\alpha}{2}\right).
\]

半角不是经验常数。把纯向量四元数 `p=(0,v)` 代入 `q p q^*`，标量项抵消，向量项中的双线性乘积产生 `\sin\alpha` 和 `1-\cos\alpha`，恰好得到 Rodrigues 公式。因而若把 30° 直接代入 `sin()` 而不除以 2，实际旋转会变成 60°。

对一段采样周期内近似恒定的角速度，可以不用显式 Euler，而使用增量四元数：

\[
\theta=\|\omega\|\Delta t,\quad
\delta q=\left(\cos\frac\theta2,\;\frac{\omega}{\|\omega\|}\sin\frac\theta2\right),\quad
q_{k+1}=\operatorname{normalize}(q_k\otimes\delta q).
\]

当 `θ` 很小时，使用 `sin(θ/2)/θ≈1/2` 的极限避免除零。按当前源码的右乘约定，参考实现如下；若验证发现旋转方向相反，应整体改为左乘，而不能只改一个分量的符号。

```c
static void quat_integrate_exp(float gx, float gy, float gz, float dt)
{
    if (!(dt > 0.0f) || !isfinite(dt)) return;
    float theta = sqrtf(gx*gx + gy*gy + gz*gz) * dt;
    float half = 0.5f * theta;
    float k;
    if (theta < 1.0e-6f) {
        k = 0.5f * dt;             // sin(theta/2)/|omega|
    } else {
        k = sinf(half) / (theta / dt);
    }
    float dq0 = cosf(half);
    float dq1 = gx * k, dq2 = gy * k, dq3 = gz * k;
    float n0 = q0*dq0 - q1*dq1 - q2*dq2 - q3*dq3;
    float n1 = q0*dq1 + q1*dq0 + q2*dq3 - q3*dq2;
    float n2 = q0*dq2 - q1*dq3 + q2*dq0 + q3*dq1;
    float n3 = q0*dq3 + q1*dq2 - q2*dq1 + q3*dq0;
    float inv = invSqrt(n0*n0+n1*n1+n2*n2+n3*n3);
    if (inv > 0.0f) {
        q0=n0*inv; q1=n1*inv; q2=n2*inv; q3=n3*inv;
    }
}
```

该函数中的 `dt` 必须是秒。仓库的 `Get_AHRS_Time()` 返回 `dt/2`，所以调用时应使用 `2.0f * Get_AHRS_Time()`；直接传入返回值会让旋转速度缩小一半。

## 10. 由四元数推导代码中的三个角

从 `R(q)` 的第三行/列元素可以得到

\[
\sin\phi=2(q_0q_2-q_1q_3),\quad
\tan\theta=\frac{2(q_0q_1+q_2q_3)}{q_0^2-q_1^2-q_2^2+q_3^2},
\]
\[
\tan\psi=\frac{2(q_0q_3+q_1q_2)}{q_0^2+q_1^2-q_2^2-q_3^2}.
\]

这三式正对应 `IMU.c:339-341` 的 `asin/atan2`。建议在源码中显式保护 `asin`：

```c
float s = 2.0f * (q0*q2 - q1*q3);
s = s < -1.0f ? -1.0f : (s > 1.0f ? 1.0f : s);
angle.roll = asinf(s) * RAD_TO_ANGLE;
```

`atan2` 的两个参数同时接近零时，角度对噪声极其敏感；这正是 pitch 接近 ±90° 时的万向节锁。控制器可直接使用四元数误差 `q_e=q_{des}^*\otimes q` 的向量部，只有通信层才转换为 `Angle_t`。

## 11. 可执行的转换验收

一个不依赖硬件的测试应覆盖三个层次：

1. 轴角 `(+x,90°)`、`(+y,90°)`、`(+z,90°)` 的旋转矩阵是否把单位轴送到预期方向；
2. 随机生成不接近 pitch 奇异点的欧拉角，执行 `euler→q→euler`，误差是否小于例如 `1e-4°`；
3. 连续积分 10 s 后检查 `fabsf(q·q-1)<1e-5`，并检查相邻四元数点积为正（必要时把新 q 整体取负）。

伪代码示例：

```c
for (int k = 0; k < 10000; ++k) {
    quat_integrate_exp(0.0f, 0.0f, 1.0f, 0.001f);
    if (q0*q0+q1*q1+q2*q2+q3*q3 < 0.9999f) fail_norm++;
}
```

恒定 `1 rad/s` 绕 z 轴运行 10 s，最终 yaw 应接近 `10 rad` 折返后的角度；若结果为 `5 rad` 或符号相反，优先检查 `halfT`、乘法方向和角速度单位，而不是调滤波增益。

## 12. `Quat_Init` 的失败路径

`Quat_Init` 只有在 `i2cread()` 返回 0 时才给 `initMx/initMy/initMz` 赋值；而当前 `i2cread()` 总返回 0，所以硬件断线时仍会把未定义数据用于 `atan2`。初始化接口应返回成功标志，并在磁场模长、I²C ACK 和水平姿态检查通过后再写入 q：

```c
bool Quat_Init_Safe(void)
{
    int16_t mx, my, mz;
    if (!read_mag_i16(&mx, &my, &mz)) return false;
    float n2 = (float)mx*mx + (float)my*my + (float)mz*mz;
    if (!(n2 > 100.0f) || !isfinite(n2)) return false;
    /* 计算倾角补偿后的 yaw，再构造并归一化 q。 */
    return true;
}
```

这样可以把“姿态初始化失败”与“姿态为零度”区分开来，也避免系统在传感器故障时悄悄使用随机四元数。
